# Look around

You are `ubuntu`, a regular (non-admin) user, inside your own isolated Linux machine. Nothing you do here can affect anyone else, so feel free to experiment.

Check who you are:

```bash
whoami
```

First, find out where you are:

```bash
pwd
```

Then list what's in this directory:

```bash
ls
```

Use `ls` with a path to look inside a directory without moving into it:

```bash
ls projects
```

> **Tip:** click **Run** on any code block to send it to the terminal.
